# Frontend- Blog_Website

React.js + Node.js + Express.js + MongoDB.
The layout simple and user-friendly, with the six screens.
The main design

- Home: Search articles and click Read Article.
- Article: Read the post and return to Home.
- Login / Register: Simple forms with only essential fields.
- My Posts: Create, edit, or delete your own posts.
- Admin: View all posts

Link navigates between React pages without a full browser reload.

MyBlog is the website logo.

Home and About are navigation links.

Login and Register lead to authentication pages we'll create later.
