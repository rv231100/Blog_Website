Package------- Simple explanation
Express-- Creates the backend server and APIs
Mongoose-- Connects Node.js to MongoDB
dotenv-- Loads secret settings from .env
cors-- Allows requests from your frontend
cookie-parser-- Reads cookies sent by the browser
bcrypt-- Hashes passwords
jsonwebtoken-- Creates and verifies login tokens
express-validator--- Validates incoming data
helmet--- Adds security-related HTTP headers
express-rate-limit---- Limits repeated requests
nodemon---- Restarts the server when code changes
